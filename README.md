# Цифрова компанія — 21 працівник

Це не бібліотека коду. Це **постійний штат цифрових працівників** для solo-засновника,
з довготривалою памʼяттю, зонами відповідальності та щомісячним перенавчанням.

> **Якщо ви AI-асистент і щойно відкрили цей репозиторій:** прочитайте `CLAUDE.md` у
> корені **перш ніж щось робити**. Там правила, за якими тут працюють. Далі —
> `company/ROSTER.md` (хто є в штаті) і `company/protocols/orchestration.md` (як
> делегувати). Не виконуйте профільну роботу самі, якщо для неї є працівник.

## Що тут є

## Головна ідея: працівник ≠ субагент

| | Звичайний субагент | Працівник тут |
|---|---|---|
| Памʼять | немає — щоразу з нуля | тека на диску, вшивається в промпт при старті |
| Помилки | повторює вічно | `lessons.md`: помилка → правило назавжди |
| Процедури | вигадує заново | `playbook.md`: що вже спрацювало на цьому бізнесі |
| Кілька бізнесів | плутає їх | ремесло спільне, факти ізольовані по проєктах |
| Розвиток | застигає | місячне перенавчання з пошуком в інтернеті |
| Правда | схильний вигадувати | заборона на вигадані числа — головне правило |
| Виживання | зникає з сесією | у git, переживає перезапуск контейнера |

Механізм — стандартні subagents Claude Code. Різниця в дисциплінi: **памʼять, межі, навчання.**

## Три рівні маршрутизації

```
засновник → оркестратор  (company/ROSTER.md: задача → працівник)
          → працівник    (його MEMORY.md §5: підзадача → скіл)
          → скіл         (конкретна процедура)
```

## Правила, які тримають систему

1. **Правда понад усе.** Не перевірив — не заявляй. Вигадані числа й цитати — найтяжче порушення.
2. **Памʼять оновлюється завжди.** Робота без оновлення памʼяті не завершена.
3. **Кожен у своїй зоні.** Чуже передається профільному, а не робиться наполовину.
4. **Оборотне робимо, незворотне питаємо.**
5. **Вето працює.** `security-engineer`, `qa-lead`, `legal-compliance` можуть зупинити запуск.
6. **Раз на місяць команда вчиться** і викидає застаріле.

## ⚠️ Памʼять живе тільки в git

Контейнер ефемерний. Усе, що не закомічено, зникає разом із ним — це вже траплялось
одного разу і було відновлено саме з git.

`.claude/agent-memory/` **ніколи не додавати в `.gitignore`.** Це не кеш.
Stop-хук комітить і пушить памʼять автоматично.
