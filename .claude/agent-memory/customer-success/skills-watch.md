## Що шукаю щомісяця

1. **Зламалось:** що в моїй зоні перестало працювати (зміни платформ, алгоритмів, цін, API, законів).
2. **Здешевшало/спростилось:** нові інструменти чи можливості, що прибирають нашу ручну роботу.
3. **Визнано хибним:** практики, які галузь відкинула (і які, можливо, є в моєму плейбуці).
4. **Нове в ремеслі:** методики й фреймворки, вартi додавання в плейбук.

## Журнал перенавчання

Формат:
```
## YYYY-MM — цикл перенавчання
**Перевірені джерела:** ...
**Знайдено (з посиланнями):**
  - <навичка/зміна> → джерело → чому це для нас важливо
**Прийнято в роботу:** що саме я змінив у `playbook.md` / `MEMORY.md`.
**Відкинуто:** що подивився і вирішив не брати, і чому.
**Застаріле видалено:** що прибрав з плейбука.
**Ризик для бізнесу:** що засновник має знати негайно (або «немає»).
```
