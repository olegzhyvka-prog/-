Мої рішення в зоні моєї відповідальності. Ведеться, щоб компанія не переглядала
вже закриті питання по колу і щоб через рік було зрозуміло *чому* так зроблено.

Формат:
```
## YYYY-MM-DD — <рішення>
**Контекст:** що змусило вирішувати.
**Розглянуті варіанти:** А (плюси/мінуси), Б, В.
**Рішення:** що саме вибрано.
**Причина:** чому саме це.
**Наслідки:** що ми свідомо приймаємо як мінус.
**Перегляд:** за якої умови або дати повертаємось до питання.
```
