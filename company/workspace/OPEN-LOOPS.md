# Відкриті контури

Те, що **не можна загубити**, але що не є поточною задачею.

`ACTIVE.md` тримає одну задачу і скидається, коли вона закрита. Контури живуть довше за
задачі: чекаємо відповідь, треба повернутись до рішення, висить непідтверджене припущення,
робота стоїть без доступу. Без цього файлу вони зникають разом із сесією, і згадуються
через місяць — випадково.

`SessionStart`-хук показує відкриті контури на старті. `Stop`-хук комітить цей файл разом
із памʼяттю.

**Контур закривається тільки з причиною.** Рядок «можна відкривати знову» — це захист від
того, щоб уже відкинута ідея повернулась через півроку як нова.

---

## Формат

```
### <коротка назва>
**Стан:** відкритий | 🚧 заблокований | 🔵 відкладений
**Власник:** засновник | оркестратор | <slug працівника> | зовнішній
**Ризик:** низький | середній | високий
**Наступна безпечна дія:** <один крок, не план>
**Потрібен дозвіл:** ні | так — <який саме>
**Посилання:** <файл · рішення · задача>
**Відкрито:** YYYY-MM-DD
```

Закриття — переносом у розділ «Закриті» з трьома додатковими рядками:

```
**Підсумок:** виконано | вбито | замінено | 🔵 відкладено безстроково
**Причина:** <чому саме так, а не інакше>
**Можна відкривати знову:** ні | так | лише з новими даними
```

---

## Правила

**Контур — не задача.** Задача має виконавця і результат. Контур — це відкрите питання
або незакритий хвіст. Якщо для нього вже є тех-завдання і працівник — це задача, її місце
в `ACTIVE.md`.

**Ризик ставиться чесно.** «Високий» означає: якщо про це забути, буде дорого або
незворотно. Якщо все високе — шкала не працює.

**Наступна дія — один крок.** Не «розібратись із оплатами», а «спитати засновника,
яка юрисдикція». Крок, який можна зробити за один захід.

**Заблокований контур називає блокер.** «🚧 заблокований» без відповіді на «чим саме»
недійсний — саме так речі висять місяцями.

**Закриті не видаляються.** Вони і є захист від повторного відкриття. Коли їх стане
багато — старші за півроку переносяться в `company/ledger/decisions.md` як записи
з підсумком.

**Посилання:** `company/ledger/decisions.md`, запис 2026-08-02 · `report-part4-memory-governance.md`, розділ «БЛОКЕР»
**Відкрито:** 2026-08-01

Уся памʼять компанії (`.claude/agent-memory/`, `company/ledger/`, протоколи) лежить
у публічному репозиторії — перевірено через GitHub API, `"private": false`. `memory-guard.sh`
цього не ловить: він шукає секрети і числа бізнесу, а не оцінює видимість репо.

Перевірено 2026-08-02: **оркестратор не може закрити репозиторій сам.** У наборі
GitHub-інструментів сесії немає зміни видимості; прямий GitHub API через проксі
повертає 403. Робить тільки засновник.

**Два наслідки, що діють прямо зараз:**

1. `company/founder-profile.md` заповнений лише операційною частиною. Фінансові
   орієнтири і портфельна стратегія не переносяться сюди.
2. **Жодні доступи не записуються у файли цього репозиторію** — ні до VPS, ні до
   сервісів, ні тимчасово. `Stop`-хук комітить і пушить `company/` та
   `.claude/agent-memory/` після кожного ходу, тому ключ у цих теках публікується
   автоматично, ще до того, як його встигнуть прибрати.
