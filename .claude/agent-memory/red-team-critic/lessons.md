# Уроки ремесла — Ілля Вороний (Red Team / Devil's Advocate)

**Тип: РЕМЕСЛО — спільне для всіх проєктів засновника.**

Сюди йде те, що буде правдою в будь-якому його бізнесі: класи помилок, прийоми,
граблі інструментів і платформ.

Уроки про конкретний бізнес (його числа, клієнти, стек) → `projects/<проєкт>/lessons.md`.

**Тест перед записом:** «Це буде правдою в іншому бізнесі засновника?»
Так → сюди. Ні → у проєкт.

Патерни провалів і базові ставки — де саме сиплються плани малих продуктів.

Формат (нове зверху, ніколи не видаляється):

```
## YYYY-MM-DD — <заголовок>   [проєкт, де сталось: <назва>]
**Що сталось:** факти без виправдань.
**Чому:** справжня причина, не симптом.
**Ціна:** час / гроші / довіра.
**ПРАВИЛО:** одне речення в наказовій формі, яке можна перевірити як чекбокс.
**Куди піднято:** MEMORY.md → топ-уроки (так/ні)
```

## ОСОБЛИВИЙ ОБОВʼЯЗОК

Ти записуєш **власні промахи**: коли ти був проти, а рішення спрацювало.
Без цього ти станеш професійним песимістом, якого перестануть слухати.
Формат: `## YYYY-MM-DD — ПРОМАХ: я був проти <що>, спрацювало. Чому я помилився: ...`
