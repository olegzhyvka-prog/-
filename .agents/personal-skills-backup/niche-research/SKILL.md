# Niche Research — Аналіз ніші до першого рядка коду

## Чому це критично

Без аналізу ніші виникають системні помилки:
- **Неправильна модель оплати** — "кількість годин" коли треба "конкретна задача"
- **Хибна структура послуг** — окремі картки замість єдиного "все-в-одному"
- **Слабкий офер** — "знижка 20%" коли конкуренти продають "виїзд за 60 хв"
- **Помилковий UX модала** — поля що не відповідають реальному процесу замовлення

---

## КРОК 1 — Конкурентний аналіз (5 хвилин, 3 пошуки)

### Пошуковий алгоритм

```
1. "{назва послуги} {місто} сайт"         → знайти 3-5 прямих конкурентів
2. "{назва послуги} {місто} ціни 2025"    → зрозуміти модель оплати і цінові рівні
3. "{назва послуги} {місто} відгуки"      → зрозуміти що важливо клієнтам
```

### Що витягти з конкурентів

Зайди на 2-3 сайти і знайди відповіді:

| Питання | Де шукати |
|---------|-----------|
| Як вони продають — задача чи час? | Hero секція, кнопка CTA |
| Яка мінімальна ціна виклику? | Прайс, калькулятор |
| Що обіцяють у Hero? | Заголовок, підзаголовок |
| Які послуги виділяють окремо? | Блок послуг |
| Яка гарантія? | Блок переваг |
| Який процес замовлення? | Форма, кроки |

---

## КРОК 2 — Ніша-специфічна модель оплати

Кожна ніша має свою логіку. Визнач правильну ПЕРЕД проектуванням модала.

### Моделі оплати по нішах

**Погодинна оплата (клієнт розуміє час):**
- Прибирання квартири
- Догляд за дітьми / літніми людьми
- Репетитор, тренер

**За задачею (клієнт не знає час — знає ПРОБЛЕМУ):**
- Чоловік на годину ← клієнт каже "зламався кран", не "потрібно 2 години"
- Ремонт техніки ← клієнт каже "не включається", не "витрать 3 години"
- Виклик лікаря ← клієнт каже "болить горло", не "огляд 30 хвилин"

**За курсом / пакетом:**
- Лазерна епіляція ← курс 6 сеансів, не "скільки годин"
- Фітнес, навчання ← місячний абонемент
- Психолог ← пакет 5/10 сесій

**За об'єктом:**
- Малярство ← ціна за м²
- Укладка плитки ← ціна за м²
- Ландшафтний дизайн ← ціна за сотку

## КРОК 3 — UX модала під нішу

### Чоловік на годину (задача)

❌ Неправильно:
```
Оберіть послугу: [Малярство ▼]
Кількість годин: [1][2][3][4][5]
Ціна: 400 × 2 = 800 грн
```
Чому погано: клієнт не знає скільки годин займе його задача.

✅ Правильно:
```
Опишіть що треба зробити: [_________________________]
Зручний час: [Сьогодні ▼] [9:00-12:00 ▼]
Ваш телефон: [+38___]
→ [Викликати майстра] ← майстер сам оцінить і назве ціну
```

### Лазерна епіляція (курс)

✅ Правильно:
```
Зона: [Ноги ▼]
Кількість сеансів: [1][2][3][4][5][6] ← клієнт знає курс
Ціна: 1200 × 6 = 7200 → зі знижкою 5760 грн
```

### Малярство (м²)

✅ Правильно:
```
Площа приміщення: [___] м²
Тип робіт: [Фарбування ▼]
Орієнтовна ціна: [авто-розрахунок]
```

## КРОК 4 — Структура Hero під нішу

### Для "задача-нікших" (майстер, ремонт, лікар):

**Заголовок формула:** Вирішимо [ПРОБЛЕМУ] за [ЧАС]
```
"Будь-який ремонт вдома — сьогодні" (не "майстер на годину з 9:00")
"Зламалось? Полагодимо за 2 години" (не "годинна ставка 400 грн")
```

**Підзаголовок:** Конкретні типи задач, не послуги:
```
"Кран, розетка, двері, меблі, плитка — один дзвінок вирішує все"
```

**CTA кнопка:** Дія, не "замовити":
```
"Описати задачу" / "Викликати майстра" / "Отримати ціну"
```

### Для "курс-нікших" (б'юті, навчання):

**Заголовок формула:** [РЕЗУЛЬТАТ] за [КІЛЬКІСТЬ] [процедур/занять]
```
"Гладка шкіра назавжди — за 6 сеансів"
```

**CTA:** "Записатись" / "Обрати зону"

## КРОК 5 — Блок послуг під нішу

### Задача-ніша: НЕ окремі картки по спеціалізаціях

❌ Неправильно (плутає клієнта):
```
[Малярство] [Електрика] [Сантехніка] [Монтаж] [Шпаклівка] [Меблі]
```
Клієнт думає: "а якщо мені треба і це і те — двох майстрів?" або "мені треба просто кран, в яку картку клікати?"

✅ Правильно — **типові задачі клієнтів:**
```
[Зламався кран / протікає труба]   → Виклик майстра + ціна ОТ
[Не працює розетка / вимикач]      → Виклик майстра + ціна ОТ
[Треба зібрати меблі з магазину]   → Виклик майстра + ціна ОТ
[Тріснула стіна / відпала плитка]  → Виклик майстра + ціна ОТ
[Треба повісити карниз / полицю]   → Виклик майстра + ціна ОТ
[Скрипить, не закривається двері]  → Виклик майстра + ціна ОТ
```

Або: **список задач текстом** у одному блоці + єдина кнопка "Викликати майстра".

### Курс-ніша: Зони/напрямки з вибором в модалі

```
[Ноги] [Бікіні] [Обличчя] [Руки] [Пахви] [Спина]
→ клік → модал з вибором кількості сеансів і ціною
```

## Приклади по нішах

### Чоловік на годину (перевірено)

```
Модель: За задачею
CTA: "Викликати майстра" / "Описати задачу"
Мін. ціна: від 400 грн виїзд + робота
Конкуренти продають: "Будь-яка дрібна робота вдома"
Типові задачі: кран, розетка, двері, меблі, карниз, кріплення
Модал: [Що треба зробити] + [Телефон] + [Час виїзду]
НЕ РОБИТИ: вибір "кількість годин" — клієнт не знає
```

### Лазерна епіляція (перевірено)

```
Модель: За курсом (6 сеансів)
CTA: "Записатись" / "Обрати зону"
Мін. ціна: від 400 грн / сеанс
Конкуренти продають: результат ("гладка шкіра назавжди")
Типові задачі: вибір зони тіла
Модал: [Зона] + [Кількість сеансів] + [Ціна авто] + [Телефон]
НЕ РОБИТИ: погодинна оплата
```

### Малярні роботи (квартирний ремонт)

```
Модель: За м² або фіксована за кімнату
CTA: "Розрахувати вартість" / "Замовити виїзд замірника"
Мін. ціна: від 80 грн/м²
Конкуренти продають: "безкоштовний замір"
Типові задачі: пофарбувати кімнату, поклеїти шпалери, шпаклювання
Модал: [Площа м²] + [Тип робіт] + [Телефон] → "Розрахувати"
```

### Доставка їжі / кур'єр

```
Модель: За замовленням (фіксована доставка або % від суми)
CTA: "Замовити" / "Оформити доставку"
Типові задачі: конкретна страва, тип кухні
Модал: НЕ потрібен — пряме меню/кошик
```

```
НІША: Чоловік на годину

МОДАЛ: [Опис задачі] + [Час] + [Телефон]
БЛОК ПОСЛУГ: Типові задачі (не спеціалізації)
ОФЕР: Виклик за 60 хв / Безкоштовна оцінка
```
