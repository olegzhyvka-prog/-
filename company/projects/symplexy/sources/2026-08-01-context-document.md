## 1. ЩО ТАКЕ SYMPLEXY (поточний стан)

**Symplexy** (symplexy.ai) — україномовний каталог AI-інструментів з інтерактивним асистентом, що допомагає підприємцям підібрати потрібний AI-сервіс під конкретну задачу.

### Формула продукту в одному реченні:
> Користувач описує задачу текстом → асистент аналізує і рекомендує 1–3 AI-інструменти з пояснення → користувач переходить на інструмент за афіліат-посиланням.

### Ключові характеристики:
- **Мова:** Українська (основна), English (в планах)
- **Каталог:** ~200 AI-інструментів у 63 підкатегоріях
- **Точка входу:** Асистент-чат на головній сторінці (не навігація по каталогу)
- **Модель:** Безкоштовна для кінцевого користувача
- **Монетизація:** Афіліат/партнерські програми (основна), платні лістинги (в планах)
- **URL:** https://symplexy.ai

---

## 2. ПИВОТ — ЩО ЗМІНИЛОСЬ (КРИТИЧНО ВАЖЛИВО)

### ❌ ВЖЕ НЕ ЧАСТИНА SYMPLEXY:
- **Платна автоматизація** — впровадження автоматизацій під ключ для бізнесу
- **Мікроавтоматизації** — простіші Make.com/Zapier workflows
- **Комплексні системи** — складні multi-step автоматизації
- **Модель "2 продукти"** (безкоштовний підбір + платне впровадження) — СКАСОВАНА

### ✅ ЩО ЗАЛИШИЛОСЬ:
- Каталог AI-інструментів (~200 штук)
- Асистент для підбору інструментів
- Афіліат-монетизація

### Де автоматизація?
Автоматизації виділені в **окремий продукт / окремий лендінг** (інший сайт, не symplexy.ai). Це рішення прийнято co-founders спільно і є остаточним.

### Чому пивот?
Конфлікт у стосунках між партнерами по питанню напрямку розвитку. Symplexy залишається чистим каталогом — простішим, зрозумілішим, без операційних складнощів послуги.

## 4. ЦІЛЬОВА АУДИТОРІЯ

**Основна ЦА:** Українські підприємці малого і середнього бізнесу (SMB), які:
- Чули про AI, але не знають з чого почати
- Не мають технічного бекграунду
- Шукають конкретні інструменти під конкретні задачі
- Читають українською / думають по-українськи

**НЕ ЦА:** Розробники, технічні фахівці, великий корпоративний бізнес

**Болі ЦА:**
- "Стільки AI-інструментів — не знаю що взяти"
- "Чи підійде це для мого бізнесу?"
- "ChatGPT — це все що є? Або є щось краще для моєї задачі?"

## 8. АУДИТ ЛЕНДІНГУ — КЛЮЧОВІ ВИСНОВКИ
*(Проведено липень 2026, два незалежних аудити: claude.ai + Claude Code/Opus)*

### Що вже було виявлено як проблеми:
1. **Нуль соціальних доказів** — немає відгуків, кейсів, кількості користувачів
2. **Немає цін** (було критично для моделі з автоматизацією — тепер не актуально в тому контексті)
3. **6 конкуруючих CTA** на сторінці замість одного основного
4. **Розбита математика** у блоці "економія годин" (суміш одиниць)
5. **Термінологія несинхронізована** — "ШІ", "нейромережі", "нейронки" на одній сторінці
4. **Унікальне позиціювання не вимовлено** — "ми єдині хто скаже що автоматизація не потрібна" ніде не написано (тепер не актуально після пивоту)
5. **Кількість інструментів** — 50 показано, 63+ у базі (розбіжність)
6. **Оцінка Figma-макету:** ~7.5/10
