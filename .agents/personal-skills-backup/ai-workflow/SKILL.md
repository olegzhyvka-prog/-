## ЧАСТИНА 2 - Задачі Соло-Фаундера → Правильний AI

### Контент і маркетинг
```
Написати пост для соцмереж:
→ ChatGPT-4o (GPT краще пише Ukrainian/Russian casual tone)
→ Промпт: tone + аудиторія + платформа + мета

Написати SEO статтю:
→ Claude Sonnet (краще структурує довгий текст)
→ + SurferSEO для ключових слів

Зробити рекламний креатив (зображення):
→ Midjourney + Canva для тексту
→ або DALL-E 3 прямо в ChatGPT

Зробити відеорекламу без актора:
→ HeyGen (AI аватар) або Runway (motion)
→ ElevenLabs (голос)
```

### Розробка і продукт
```
Написати код:
→ Claude Sonnet або Opus (кращий для архітектурних рішень)
→ GPT-4o (швидше для snippets)
→ Claude Code (для повних проектів)

Зробити лендінг:
→ Мій pipeline: Claude HTML → Netlify Drop
→ або Lovable (якщо потрібен React)

Дебажити помилку:
→ Claude (краще пояснює "чому" + рішення)

Зробити прототип:
→ v0.dev (швидкий React UI)
→ або Bolt.new (повний stack)
```

### Аналіз і дослідження
```
Аналіз ринку / конкурентів:
→ Claude + web search
→ або Perplexity Pro (реальний час + джерела)

Аналіз даних з Excel/CSV:
→ ChatGPT Advanced Data Analysis
→ або Claude з Data Analysis mode

Читання і summary документів:
→ Claude (кращий довгий контекст + точність)
→ Gemini 1.5 Pro (якщо документ > 100 сторінок)

Дослідження трендів:
→ Perplexity AI (реальний час)
→ Claude + пошук для глибини
```

### Автоматизація
```
Зв'язати два сервіси:
→ Make.com (візуально) або Zapier (простіше)

AI агент для рутини:
→ Make.com + Claude API
→ або Relevance AI (no-code агенти)

Автовідповіді / чатбот:
→ Manychat (Facebook/Instagram)
→ або Tidio / Intercom + AI

Парсинг і збір даних:
→ Apify (no-code scraping)
→ або Browse AI
```

## ЧАСТИНА 4 - Побудова AI Pipeline

### Принцип: кожна задача → свій AI → свій вихід

```
ЗАДАЧА: Написати серію постів для Instagram

PIPELINE:
1. Claude  →  Контент-стратегія і теми (структура)
2. GPT-4o  →  Написати 10 постів (casual tone)
3. DALL-E  →  Зображення для кожного поста
4. Make    →  Автопублікація за розкладом
5. Claude  →  Аналіз результатів (що зайшло)
```

```
ЗАДАЧА: Лідогенерація для B2B

PIPELINE:
1. Apify       →  Збір контактів (Google Maps / LinkedIn)
2. Claude API  →  Персоналізація меседжу для кожного
3. Make.com    →  Відправка через email / WhatsApp
4. Claude      →  Аналіз відповідей і наступний крок
```

## ЧАСТИНА 5 - Правила ефективної роботи з AI

```
1. Контекст - ключ. Чим більше контексту → тим точніший результат.
   Поганий: "Напиши пост про сайти"
   Хороший: "Ти - копірайтер для Symplexy (AI-каталог для підприємців).
   Напиши пост в Instagram про те як обрати правильний AI інструмент.
   Аудиторія: підприємці 25-45. Тон: прямий, без води. Мета: клік."

2. Ітерація. Перший результат - чернетка. Давай feedback і уточнюй.

3. Розподіл ролей. Claude для думання, GPT для писання, Midjourney для картинок.

4. Системні промпти > разові запити. Один раз налаштуй - використовуй постійно.

5. Перевіряй факти. AI може вигадувати цифри і посилання.
```
