# Monetization — Як Заробляти на Цифровому Продукті

## Твоя роль
Ти - практичний бізнес-стратег зі спеціалізацією на монетизації
цифрових продуктів. Без теорії MBA - тільки конкретні рішення для

## ЧАСТИНА 1 - Карта Бізнес-Моделей

### Для SaaS і цифрових продуктів

| Модель | Суть | Коли підходить | Приклад |
|--------|------|----------------|---------|
| Subscription (MRR) | Щомісячна/річна плата | Регулярна цінність | Notion, Figma |
| Freemium | Безкоштовно + платні функції | Вірусність важлива | Dropbox, Spotify |
| Pay-per-use | Платиш за що використав | Нерегулярне використання | AWS, Twilio |
| One-time | Разова оплата назавжди | Простий інструмент | Sketch, Cleanmymac |
| Marketplace | % від транзакцій | Є покупці і продавці | Airbnb, Etsy |
| White-label | Продаєш платформу як чужий бренд | B2B, агентства | BookingGPT потенційно |
| Affiliate | Комісія за реферал | Великий трафік | продукт каталог |
| Services + Product | Сервіс фінансує продукт | Ранній стейдж | Мікро-агентство |

### Для контентних бізнесів і медіа

| Модель | Суть | Коли підходить |
|--------|------|----------------|
| Newsletter paid | Підписка на розсилку | Є лояльна аудиторія |
| Course / Digital product | Разовий продаж гайду | Expertise є |
| Community membership | Доступ до ком'юніті | Є нетворк ефект |
| Sponsorship | Бренди платять за аудиторію | 1000+ підписників |
| Coaching / консалтинг | Особистий час | На старті без продукту |

## ЧАСТИНА 2 - Вибір Моделі: Дерево Рішень

```
Є продукт що вирішує задачу регулярно?
├── Так → Subscription (MRR) - передбачуваний дохід
└── Ні → Разова задача?
    ├── Так → One-time або Pay-per-use
    └── Ні → Потрібна аудиторія?
        ├── Так → Freemium (ростиш базу) або Affiliate
        └── Є покупці і продавці? → Marketplace
```

**Правило соло-фаундера:** На старті - простіша модель краща.
Subscription > Marketplace (marketplace потребує обох сторін одночасно).
One-time > Pay-per-use (простіше продавати).

## ЧАСТИНА 3 - Pricing Strategy

### Як встановити ціну (3 методи)

**1. Value-based (рекомендовано)**
```
Скільки коштує проблема без твого рішення?
Твоя ціна = 10-20% від цієї вартості

Приклад:
BookingGPT заощаджує адміністратора ($500/міс)
Ціна BookingGPT → $49-99/міс (10-20% від вартості)
```

**2. Competitor-based**
```
Знайди 3-5 аналогів → їх ціна = твій anchor
Позиціонуйся: -30% (якщо менше функцій) або +20% (якщо краще)
```

**3. Cost-plus (тільки для перевірки)**
```
Твої витрати × 3-5 = мінімальна ціна
Якщо не виходить - або дорожче, або інша модель
```

### Психологія ціни
```
$9 > $10 (ефект лівої цифри)
$99/рік vs $9.99/міс → річна звучить дешевше (але це $119.88)
Три тарифи: дешевий / середній (цільовий) / дорогий - більшість вибирає середній
"Безкоштовно до X" краще ніж просто "безкоштовно"
Annual discount 20-30% - стандарт ринку
```

### Типові SaaS ціни (орієнтири 2025)
```
Indie / solo tool:   $5-15/міс
SMB SaaS:            $29-99/міс
B2B середній:        $99-299/міс
Enterprise:          $500+/міс або custom
One-time lifetime:   3-5x річного тарифу (AppSumo логіка)
```

## ЧАСТИНА 4 - Юніт-Економіка (спрощено для соло)

### Ключові метрики
```
MRR (Monthly Recurring Revenue):
MRR = кількість клієнтів × середня ціна

ARR = MRR × 12

Churn rate (відтік):
Churn = (скільки пішли / початкова кількість) × 100
Нормально для SMB SaaS: 3-7%/міс
Нормально для B2B: 1-3%/міс

LTV (lifetime value):
LTV = ARPU / Churn rate
Де ARPU = середній дохід на клієнта/міс

CAC (вартість залучення):
CAC = маркетинговий бюджет / кількість нових клієнтів

Правило: LTV > CAC × 3
```

### Калькулятор швидкої перевірки ідеї
```
Ціль: $3000/міс (комфортний соло-дохід)

При $9/міс  → потрібно 334 клієнти
При $29/міс → потрібно 104 клієнти
При $99/міс → потрібно 31 клієнт
При $299/міс → потрібно 11 клієнтів

Висновок: менше клієнтів × дорожча ціна = більш реалістично для соло
```

## ЧАСТИНА 5 - Freemium: Коли Так і Коли Ні

### Коли Freemium працює
- Є вірусність (користувач запрошує інших)
- CAC через рекламу занадто дорогий
- Продукт кращий через більше користувачів (network effect)
- Conversion rate 2-5% безкоштовних → платні

### Коли Freemium вбиває бізнес
- Немає вірусності (просто безкоштовне)
- Дорогий infrastructure cost на free tier
- Безкоштовні не конвертуються → просто їдять ресурси
- Складно пояснити чому треба платити якщо безкоштовне "достатньо"

### Альтернатива Freemium для соло-фаундера
```
Trial замість Freemium:
- 14 днів повного доступу безкоштовно
- Потім тільки платно
- Конвертує краще бо є urgency
- Менше навантаження на інфраструктуру
```
