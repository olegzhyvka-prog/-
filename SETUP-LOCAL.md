# Що доставити з компʼютера

Усе з цього файлу **не можна закріпити через репозиторій** — воно ставиться
локально на твою машину. Скіли й MCP-браузер уже в репо і працюють після
`git pull`, тут лише те, що потребує установки.

Порядок має значення: пункт 1 дає найбільший ефект.

---

## 1. claude-mem — памʼять між сесіями

**Навіщо:** зараз кожна сесія починається з нуля. Це найбільша прогалина —
жоден із 83 наявних скілів її не закриває.

```bash
npx claude-mem install
```

Потрібно: Node.js 20+. Bun, SQLite і uv доставляться самі.
Далі перезапусти Claude Code — памʼять вмикається через хуки автоматично.

Перевірка: почни нову сесію і спитай «що ми робили минулого разу».

---

## 2. Playwright MCP — браузер для агента

Конфіг **уже в репо** (`.mcp.json`). Після `git pull` Claude Code сам
запропонує підключити сервер — треба один раз підтвердити.

Якщо не запропонував:

```bash
claude mcp add playwright npx @playwright/mcp@latest
```

**Навіщо:** відкривати сторінки, заповнювати форми, збирати дані без API.
Основа для LLM Visibility і скрейпінгу.

---

## 3. Agent-Reach — доступ до платформ

**Навіщо:** X/Twitter, Reddit, YouTube, LinkedIn, GitHub як джерела даних.
Без API-ключів і без оплати.

```bash
pip install agent-reach
agent-reach install
```

Потрібно: Python 3.10+. Node.js і gh CLI доставить сам.

⚠️ У пошуку багато форків-клонів з однаковим описом. Канонічний репозиторій —
`github.com/Panniantong/Agent-Reach`. Став тільки з нього.

---

## 4. Ruflo — рішення на потім, не ставити зараз

Ти питав саме про нього, тому пояснюю розгорнуто.

Swarm-скіли там справді є і вони справді про команду агентів. **Але їх не можна
просто скопіювати в репо** — це обгортки над власним MCP-стеком Ruflo. Я
порахував посилання на `mcp__claude-flow__*` / `npx ruflo` всередині файлів:

| Скіл | Посилань на стек Ruflo |
|---|---|
| hooks-automation | 116 |
| sparc-methodology | 94 |
| swarm-advanced | 80 |
| verification-quality | 73 |
| hive-mind-advanced | 39 |
| swarm-orchestration | 11 |

Скопійовані окремо — це інструкції, що викликають неіснуючі інструменти.
Тобто зламані скіли.

Щоб вони працювали, треба поставити платформу цілком:

```bash
npx ruflo init
```

Це 314 MCP-інструментів, власна система хуків і перехоплення маршрутизації
задач. Серйозна зміна поведінки Claude Code.

**Моя рекомендація:** спершу поживи місяць з `agent-teams` (уже в репо, працює
на рідній функції Claude Code, нуль залежностей). Якщо впрешся в його стелю —
тоді Ruflo, окремою сесією, з часом на розбір.
