# Competitor Intelligence

## Мета
Знайти де конкурент слабкий, де ринок незайнятий, і як на цьому побудувати перевагу.

---

## Алгоритм

### Крок 1 — Ідентифікація гравців
Категорії конкурентів:
- **Прямі** — роблять те саме для тієї самої аудиторії
- **Непрямі** — вирішують ту саму проблему інакше
- **Потенційні** — можуть зайти в нішу

### Крок 2 — Профіль кожного гравця

Для кожного конкурента:
- Продукт: що продають, які фічі, яка модель монетизації
- Аудиторія: хто ICP, яка розмір бізнесу, географія
- Позиціювання: головний меседж, УТП
- Ціноутворення: тарифи, моделі (freemium / subscription / one-time)
- Канали: де рекламуються, яка SEO-присутність, соцмережі
- Слабкі місця: негативні відгуки, скарги, обмеження

### Крок 3 — Порівняльна матриця

| Критерій | Конкурент A | Конкурент B | Ми |
|----------|-------------|-------------|-----|
| Ціна | | | |
| Швидкість онбордингу | | | |
| Ключова фіча | | | |
| Підтримка | | | |
| Інтеграції | | | |

Оцінка: ✅ сильно / ⚠️ середньо / ❌ слабко

### Крок 4 — Аналіз відгуків конкурентів
Що клієнти хвалять → що цінують
Що клієнти критикують → де біль незакритий

Джерела: G2, Capterra, Reddit, App Store, коментарі TikTok/YouTube

### Крок 5 — Прогалини ринку
Що ніхто не закриває добре? Яка аудиторія недообслужена? Яка цінова ніша порожня?

### Крок 6 — Стратегічний висновок
- Де атакувати (де ми можемо виграти)
- Де не йти (де програємо за визначенням)
- Унікальне позиціювання яке важко скопіювати

## Джерела для ресерчу (використовуй web search)

**Продукт і позиціювання:** сайт конкурента, pricing page, about page
**Відгуки:** G2.com/[назва], Capterra, Reddit r/[ніша]
**Маркетинг:** SimilarWeb (трафік), Meta Ad Library (реклама), Ahrefs/Semrush (SEO)
**Соцмережі:** коментарі під постами, TikTok відгуки
**Вакансії:** що наймають → що будують

```
**Конкурентний ландшафт:** [загальна картина ринку]

**Ключові гравці:**
1. [Назва] — [позиціювання] — [ціна] — [слабке місце]
2. ...

**Матриця порівняння:**
[таблиця]

**Незайняті ніші:**
- [прогалина 1]
- [прогалина 2]

**Наша стратегія:**
Атакуємо: [де]
Позиціювання: [як відрізнятись]
Уникаємо: [де не змагаємось]
```

## Важливо
- Завжди шукай реальні відгуки (не припускай — шукай)
- Слабке місце конкурента ≠ наша перевага поки ми не підтвердили що вміємо це краще
- Один сильний диференціатор кращий за п'ять слабких
- Оновлювати аналіз раз на квартал — ринок змінюється
