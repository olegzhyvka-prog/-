# Model Advisor

## Мета
Перед виконанням задачі — написати ONE рядок: яка модель і який інтерфейс найкраще підходить.

## Формат виводу

```
💡 **Для цієї задачі:** [Модель] + [Інтерфейс] — [1 речення чому]
```

Потім одразу виконуй задачу. Без зайвих пояснень.

---

## Логіка вибору МОДЕЛІ

### Claude Haiku
- Простий факт, переклад, перефразування
- Класифікація, коротке резюме
- Коли потрібно швидко і дешево

### Claude Sonnet (найчастіший вибір)
- Код, скрипти, HTML/CSS, лендінги
- Контент, пости, копірайтинг
- Середньої складності аналіз
- Prompt engineering
- Більшість повсякденних задач

### Claude Opus
- Глибокий стратегічний аналіз (бізнес-модель, pivot, архітектура)
- Складне багатокрокове мислення
- Критичні рішення з довгостроковими наслідками
- Синтез великого обсягу інформації
- Фінансові моделі, юніт-економіка з багатьма змінними

---

## Логіка вибору ІНТЕРФЕЙСУ

### Claude.ai (веб/мобільний чат)
Коли:
- Стратегія, аналіз, дослідження
- Контент і копірайтинг
- Питання, консультації, мозковий штурм
- Робота зі скілами (model-advisor, content-pipeline тощо)
- Швидкий чат без файлів і коду

### Claude Code (термінал / десктоп-додаток)
Коли:
- Написання або виправлення коду
- Робота з файлами, bash, скриптами
- Деплой, автоматизація, CLI-задачі
- Великі кодові бази, рефакторинг
- MCPs: Playwright, NanoBanana, Blotato

### Cowork (десктоп-додаток)
Коли:
- Автоматизація файлів і задач без коду
- Робота з локальними документами (Word, Excel, PDF)
- Нетехнічна автоматизація на десктопі
- Drag-and-drop файлові операції

### Claude в Excel
Коли:
- Таблиці, фінансові моделі, Excel-файли
- Формули, зведені таблиці, дашборди в Excel

### Claude в PowerPoint
Коли:
- Презентації, слайди, pitch deck
- Оновлення або генерація PPTX

### Claude в Chrome (браузерний агент)
Коли:
- Автоматизація дій у браузері
- Скрапінг, заповнення форм, навігація по сайтах
- Задачі які потребують "відкрити браузер і зробити щось"

## Приклади

**Задача:** "Напиши пост для Instagram про Symplexy"
```
💡 Для цієї задачі: Sonnet + Claude.ai — контент середньої складності, зручно в чаті зі скілами
```

**Задача:** "Проаналізуй бізнес-модель Symplexy і визнач слабкі місця"
```
💡 Для цієї задачі: Opus + Claude.ai — глибокий стратегічний аналіз, консультаційний формат
```

**Задача:** "Зроби скрипт який парсить барбершопи з Google Maps"
```
💡 Для цієї задачі: Sonnet + Claude Code — написання і запуск коду, робота з файлами
```

**Задача:** "Зроби фінансову модель в Excel для мікро-агентства"
```
💡 Для цієї задачі: Sonnet + Claude в Excel — пряма робота з таблицями без експорту
```

**Задача:** "Переклади цей абзац на англійську"
```
💡 Для цієї задачі: Haiku + Claude.ai — простий переклад, швидко і дешево
```

**Задача:** "Автоматично заповни форму на сайті клієнта"
```
💡 Для цієї задачі: Sonnet + Claude в Chrome — браузерна автоматизація
```

## Важливо
- Завжди один рядок перед задачею
- Якщо поточний інтерфейс НЕ оптимальний — чітко написати: "перейди в [інтерфейс]"
- Якщо поточний інтерфейс підходить — просто виконуй задачу
- Без зайвих пояснень після рекомендації
