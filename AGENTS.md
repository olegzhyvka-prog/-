# AGENTS.md

Канонічний гайд репозиторію, нейтральний до інструменту. Claude Code читає `CLAUDE.md`
(там повні правила); цей файл — для будь-якого іншого агента чи людини, що сюди потрапила.

## Що це за репозиторій

**Цифрова компанія з 21 постійного працівника** для solo-засновника. Не бібліотека коду.
Працівники — це агенти з довготривалою памʼяттю, зонами відповідальності та щомісячним
перенавчанням.

## Перед будь-якою дією

1. **`CLAUDE.md`** — правила роботи. Обовʼязково.
2. **`company/ROSTER.md`** — хто є в штаті, кого коли кликати, у кого право вето.
3. **`company/protocols/orchestration.md`** — як делегувати роботу.
4. **`company/PROJECTS.md`** — над яким бізнесом працюємо (памʼять розділена по проєктах).

## Що ти мусиш знати одразу

- **Штат уже існує.** Не створюй працівників заново.
- **Не виконуй профільну роботу сам,** якщо для неї є працівник. Ти оркестратор.
- **Памʼять живе в git.** `.claude/agent-memory/` — не кеш, ніколи не в `.gitignore`.
  Контейнер ефемерний; усе незакомічене зникає.
- **Правда понад усе.** Не заявляй неперевіреного, не вигадуй числа, цитати й джерела.
  Немає даних → скажи «немає» і назви, що потрібно.
- **Мова спілкування із засновником — українська.**

## Гілка

Компанія живе на `claude/digital-workers-solo-founder-b2zbxz`. Якщо ти бачиш репозиторій
без `company/` і без `.claude/agents/` — ти на іншій гілці:

```bash
git fetch origin claude/digital-workers-solo-founder-b2zbxz
git checkout claude/digital-workers-solo-founder-b2zbxz
```
