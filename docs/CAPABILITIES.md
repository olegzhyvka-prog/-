# Що я роблю сам, що потрібно ззовні

Чесна карта можливостей — щоб не планувати роботу на тому чого немає,
і не платити стороннім сервісам за те що робиться тут безкоштовно.

Перевірено в цьому середовищі 2026-07-30.

## 1. Дизайн і сайти

### Роблю сам, повністю

| Що | Нотатка |
|---|---|
| Дизайн-система: токени, палітра, типографіка, тіні, сітка | `design-system` |
| Верстка лендінга: HTML/CSS/JS одним файлом | `site-builder` |
| Візуальні ефекти: mesh-градієнти, aurora, glass, шум, свічення, spotlight | `design-system/references/effects.md` |
| WebGL/Canvas шейдери, scroll-анімації, інтерактив | те саме |
| SVG: іконки, ілюстрації, патерни, логотипи-леттермарки, діаграми | генерую напряму |
| Перевірка результату: Playwright → скріншот десктоп/мобайл → правки | бачу що вийшло і виправляю сам |
| Дашборди, таблиці, графіки | `dataviz` |

### Не роблю сам
**Растрові зображення** — фото, 3D-рендери, фотореалістичні мокапи, персонажі.
Я не малюю пікселі.

### Відповідь на питання «чи йти в ChatGPT за макетом лендінга»

**Ні, і це найважливіший пункт документа.**

Картинка-макет — проміжний крок, який усе одно доведеться верстати, і при верстці
половина того що на картинці не відтворюється. Я одразу роблю **робочу сторінку**:
її можна відкрити, натиснути, залити трафік і виміряти конверсію. Це швидше
і результат кращий.

Зовнішній генератор потрібен тільки для **контентних фото** всередині сторінки.
Але для SaaS/AI-лендінга вони часто взагалі не потрібні: сучасна візуальна мова
будується на типографіці, градієнтах, скріншотах продукту і SVG.

**Коли реально треба ззовні:** фото людей, предметна зйомка, фотореалістичні мокапи
пристроїв, ілюстрації в авторському стилі. Тоді: Midjourney / Flux / Nano Banana /
GPT Image → файл кладеш у `sites/<slug>/assets/` → я вбудовую.

## 2. Відео

### Роблю сам, повністю

| Що | Інструмент |
|---|---|
| Motion-графіка: анімовані заголовки, hook-плашки, лого-стінгери, кінцівки з CTA, демо UI, інфографіка в русі | `render_motion.py` — HTML/CSS → MP4 |
| Монтаж: склейка, нарізка, темп | `assemble.py` (ffmpeg) |
| Формати 9x16 / 1x1 / 16x9 / 4x5 з одного вихідника | `assemble.py --format` |
| Субтитри вшиті в картинку | `assemble.py --subs` |
| Музика з дакінгом під голос + нормалізація −14 LUFS | `assemble.py --music` |
| Пакет варіантів під тест креативів | `batch_variants.sh` |

**Перевірено:** ролик 1080×1920, 30 fps, 5 секунд рендериться ≈ 1 хв 50 с.
15-секундний — близько 6 хвилин.

### Не роблю сам
- Знімальне відео з живими людьми, реалістичні сцени → **Kling / Veo / Runway**
- Синтез голосу → **ElevenLabs**
- Аватар що говорить → **HeyGen / Higgsfield**

Я пишу промпти під конкретну модель (`ai-video-prompts`, `ai-video-models`,
`cinematography`), тайминг і сценарій. Генеруєш ти, приносиш файли — монтую я.

### Практичний висновок
Значну частину креативів для SaaS/AI **не треба генерувати взагалі**: вони
складаються з типографіки в русі, скріншотів продукту і субтитрів. Це повний цикл
у мене. AI-генерація потрібна тільки коли в кадрі жива людина.

## 3. Обмеження середовища ⚠️

**Claude Code на вебі має закритий вихід у мережу.**

| Напрямок | Стан |
|---|---|
| GitHub | ✅ |
| npm / pip реєстри | ✅ |
| MCP-сервери (Semrush, Figma, Canva, Gamma, Supermetrics, Drive) | ✅ працюють на боці Anthropic |
| WebSearch / WebFetch | ✅ працюють на боці Anthropic |
| Довільні API з коду (fal.ai, Replicate, OpenAI) | ❌ заблоковано |
| Стокові фото (Unsplash тощо), CDN, зовнішні шрифти | ❌ заблоковано |

**Наслідки для роботи:**
1. Лендінги верстаються **без зовнішніх запитів**: системні шрифти, inline SVG,
   градієнти, data-URI. Це не обмеження якості — це ще й швидкий LCP.
2. Автоматично викачати згенероване відео з Kling/Runway сюди не вийде.
   Файли приносиш ти — в репозиторій або через Google Drive (MCP працює).
3. Мережеву політику середовища можна змінити в налаштуваннях Claude Code on the web —
   якщо потрібен доступ до конкретних API, це вирішується там:
   https://code.claude.com/docs/en/claude-code-on-the-web

## 4. MCP: що є і що варто підключити

### Підключено
| Сервер | Для чого в нашому циклі |
|---|---|
| **Semrush** | попит, CPC, трафік конкурентів, їх платна реклама — блоки 2-4 досьє |
| **Supermetrics** | факт з рекламних кабінетів → `growth-analyst` для вироку |
| **Figma** | генерація дизайну, шейдери, експорт MP4 з таймлайну |
| **Canva / Gamma** | презентації і швидкі візуали |
| **Google Drive** | канал передачі медіа-файлів між середовищами |
| **GitHub** | код і деплой |

### Варто підключити (за пріоритетом)

1. **PostHog** — найбільший розрив зараз. Воронки, теплокарти, записи сесій,
   фіче-флаги для A/B — усе в одному, безкоштовного тарифу вистачає для тестів.
   Закриває кроки 2-4 циклу.
2. **Stripe** — швидке створення Payment Link для preorder-тестів (найсильніший
   формат перевірки) і фактична виручка в аналітиці.
3. **Vercel** — деплой лендінгів прямо з розмови.
4. **Motion Creative Analytics** — розбір креативів конкурентів у бібліотеці Meta.

### Чого в директорії MCP немає
**Генерації зображень і відео.** Перевірено — таких конекторів у каталозі Claude
немає. Тобто маршрут «AI-картинка/відео» завжди йде через зовнішній інструмент,
і жодне MCP цього не змінить. Плануй так.
