## Google APIs — ліміти й барʼєри входу

`[пошук, 2026-08-04]`

**Gmail API**
- Квоти: 80 млн quota units/добу на проєкт; 1,2 млн/хв на проєкт; **15 000/хв на
  користувача**. `drafts.create` = 10 units, `drafts.send` = 100 units.
- **Квоти НЕ є вузьким місцем** на реалістичних обсягах. Вузьке місце — верифікація.
- 🔴 **Restricted scopes** (`gmail.readonly`, `gmail.modify`, `gmail.compose`,
  `gmail.insert`, `mail.google.com/`): без верифікації — **ліміт 100 користувачів**.
- 🔴 **CASA-аудит обовʼязковий і ЩОРІЧНИЙ**, якщо restricted-дані проходять через
  сторонній сервер. Вартість: лабораторії **$500–$4 500**; за досвідом розробників
  від $3 000 за Tier 2; складні кейси — до $75 000. Тривалість — не встановлено.
- ⚠️ `gmail.metadata`: джерела **суперечать** (restricted vs basic). ПЕРЕВІРИТИ на
  `developers.google.com/gmail/api/auth/scopes`. Якщо basic — дає заголовки без тіла
  листа, тобто дешевий, але функціонально бідний обхід.

**Google Calendar API**
- **$0 за виклики.** 10 000 запитів/хв на проєкт, **600/хв на користувача**,
  поріг білінгу 1 млн/добу (для проєктів, створених з 2026-05-01).

## Що переглядати в місячному перенавчанні

1. Ціни Anthropic — скіл `claude-api` кешується, дата кешу застаріває.
2. Чи не зʼявилась дешевша модель під наші типові задачі.
3. Зняті з API моделі (як DALL-E у травні 2026) — ТЗ на них треба виправляти.
4. Зміни ToS у Gamma / FLUX / OpenAI щодо перепродажу генерацій.
5. Політики Google щодо restricted scopes — вони жорсткішають, не мʼякшають.
