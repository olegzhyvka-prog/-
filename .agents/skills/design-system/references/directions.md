# Візуальні напрями — довідник для дошки референсів

Вісім різних мов дизайну. **Сім із восьми — світлі.** Темна тільки одна,
і вона обирається свідомо, а не за замовчуванням.

Кожен напрям — це не «тема», а набір рішень: палітра, типографіка, форма,
щільність, тип героя. Змішувати два напрями в одній сторінці не можна.

---

## Найперше: ознаки «AI-лендінга»

Так виглядає сторінка, яку впізнають як згенеровану за три секунди:

| Ознака | Чому це видно |
|---|---|
| Майже чорний фон `#0A0A0C` | дефолт усіх генераторів з 2024 року |
| Фіолетово-індиговий градієнт | той самий відтінок `#6D4AFF` у половини AI-продуктів |
| Свічення під кнопкою | ефект, який нічого не комунікує |
| Inter + негативний трекінг | шрифт за замовчуванням усюди |
| Центрований герой, бейдж-пігулка згори | одна композиція на всіх |
| Скляні картки з тонким бордюром | glassmorphism без причини |

**Правило:** якщо на сторінці зійшлись три з шести — це шаблон, а не дизайн.
Темний фон дозволений лише в напрямі 8, і лише коли продукт справді нічний
(інструмент розробника, трейдинг, монтаж).

---

## 1. Editorial — журнальний

Для консалтингу, послуг, B2B з довгим циклом, авторських продуктів.

```
Фон       #FBFAF7  тепла крейда
Текст     #16150F
Акцент    #B4501E  палена цегла
Заголовки Instrument Serif / Playfair — великий шрифт з засічками
Текст     системний sans, 17-18px
Форма     без радіусів або 2px. Лінійки замість карток
Герой     ліворуч вирівняний, велика цитата, тонка горизонтальна лінійка
Щільність повітряна, широкі поля
```
Сильний бік: одразу читається як «дорого і людина за цим стоїть».

## 2. Warm Minimal — теплий мінімалізм

Для продуктів про спокій, здоров'я, освіту, фінанси для людей.

```
Фон       #FAF7F2  → секції #F2EDE4
Текст     #2A2622
Акцент    #3F6B4A  приглушений зелений
Шрифти    один гротеск, вага 400/600
Форма     радіуси 14-18px, м'які великі кнопки
Герой     текст ліворуч, ілюстрація або фото праворуч
Тіні      майже немає, замість них теплі підкладки
```

## 3. Bento — модульна сітка

Для SaaS з багатьма функціями. Домінантний патерн 2026 (Apple-стиль).

```
Фон       #F6F7F9
Картки    #FFFFFF, радіус 20px, бордюр 1px #E7EAEE
Акцент    #2563EB
Сітка     плитки різного розміру: 2×1, 1×1, 1×2
Герой     короткий заголовок + одразу сітка плиток
Головне   у кожній плитці ОДИН факт і один візуал, не абзац
```
Пастка: усі плитки однакового розміру = таблиця, а не bento.

## 4. Technical — точний

Для інструментів, API, продуктів для інженерів. Світлий.

```
Фон       #FFFFFF, секції #F7F8F8
Текст     #0F1115
Акцент    #0B7285  або взагалі чорний
Шрифти    гротеск + моноширинний для чисел і термінів
Форма     радіус 4-6px, багато 1px-бордюрів, таблиці
Герой     заголовок + реальний фрагмент коду/виводу
Прикраси  жодних. Сітка, лінії, дані
```

## 5. Bold Color — плакатний

Для споживчих продуктів, застосунків, того що продається емоцією.

```
Фон       великі суцільні кольорові блоки: #F4E04D, #FF6B4A, #1B3A5C
Текст     контрастний до блока
Шрифти    дуже щільний гротеск, 800-900, великі розміри
Форма     радіус 0 або пігулки, без тіней
Герой     фон — колір, а не градієнт. Слово-гак на пів екрана
```
Необроталізм у м'якій формі: сміливість без хаосу.

## 6. Soft Product — м'який продуктовий

Найбезпечніший вибір для B2C SaaS. Світлий, дружній, без ризику.

```
Фон       #FFFFFF → #F5F8FF
Текст     #1C2434
Акцент    #4F7DF3 + вторинний #F5A623
Шрифти    гротеск з відкритими формами
Форма     радіуси 12-16px, м'які кольорові тіні
Герой     заголовок + скріншот інтерфейсу під кутом або в рамці
```

## 7. Archive — паперовий

Для контентних продуктів, спільнот, курсів, всього «людського».

```
Фон       #F0EBE1 з ледь помітною текстурою
Текст     #2B2620
Акцент    #7A3E2F
Шрифти    serif для тексту, гротеск для інтерфейсу
Форма     прямі кути, штрихові рамки, «наліпки»
Герой     багато тексту, мало зображень, як розворот книги
```

## 8. Night — темний (ЄДИНИЙ)

Тільки коли продукт справді використовується вночі або в темному середовищі:
інструменти розробника, монтаж, трейдинг, моніторинг.

```
Фон       #14161A  — НЕ чорний. Low-light, не dark mode
Текст     #E8EAED
Акцент    #5EE7C4  або бурштиновий — НЕ фіолетовий
Шрифти    гротеск + моно
Форма     радіус 8px, бордюри світліші за фон на 8%
Заборонено: фіолетовий градієнт, свічення під кнопкою, glass-картки
```
Якщо вибрано цей напрям — обов'язково зробити і світлу версію через
`prefers-color-scheme`. Дослідження 2026: бренди дають обидві.

## Як користуватись

1. `landing-builder` рендерить дошку: `scripts/render_board.py`
2. Власник дивиться і називає номер (або «1, але акцент синій»)
3. Тільки після вибору — повна верстка в обраному напрямі
4. Обраний напрям записується в `brand/<product>/BRAND.md`, щоб наступні
   сторінки продукту були в тій самій мові

**Ніколи не будуй повний лендінг без вибраного напряму.** Переробка готової
сторінки коштує в 5 разів дорожче за перегенерацію дошки.
