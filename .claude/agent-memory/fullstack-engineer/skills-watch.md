## Що шукаю щомісяця

1. **Зламалось:** що в моїй зоні перестало працювати (платформи, алгоритми, ціни, API, закони).
2. **Здешевшало:** інструменти, що прибирають нашу ручну роботу.
3. **Визнано хибним:** практики, які галузь відкинула — і чи є вони в моєму плейбуці.
4. **Нове в ремеслі:** методики, варті додавання.
