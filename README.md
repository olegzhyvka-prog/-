# Операційна система для швидких гіпотез і сайтів

Робоче місце для перевірки бізнес-гіпотез: **7 днів і $300 замість 3 місяців і $8000.**

Правила роботи — `CLAUDE.md`. Це вхідна точка, її читають першою.

---

## З чого складається

| | |
|---|---|
| `CLAUDE.md` | головний цикл, ворота між кроками, чого не робити |
| `.claude/agents/` | чотири працівники: аналітик, верстальник, продюсер креативів, аналітик росту |
| `.agents/skills/` | скіли проєкту (символьні посилання в `.claude/skills/`) |
| `company/products.md` | реєстр продуктів — **єдине джерело контексту**, заповнити першим |
| `company/LEARNINGS.md` | висновки з усіх тестів. Читати перед новою гіпотезою |
| `company/hypotheses/<дата>-<slug>/` | одна гіпотеза = одна папка: досьє, лендінг, креативи, дані |
| `docs/CAPABILITIES.md` | що робиться тут, що потрібно ззовні, обмеження середовища |
| `docs/SKILLS-AUDIT.md` | які скіли активні, які в архіві і чому |

---

## Цикл

```
ІДЕЯ → ДОСЬЄ → ЗБІРКА → РИНОК (3-7 днів) → ВИРОК → НАВЧАННЯ
        ↑ ворота: без пройденого досьє далі не йдемо
```

Найдорожча помилка — гарний лендінг для гіпотези, яку можна було вбити
за годину аналізу.

---

## З чого почати

1. Заповнити блокуючі поля в `company/products.md` — без них працівники
   зупиняються на першому ж питанні про юрисдикцію чи платежі
2. Прочитати `CLAUDE.md`
3. Сказати «є ідея: ...» — далі система веде сама

---

## Корисні команди

```bash
# економіка гіпотези: LTV, CAC, і межа при якій модель ламається
python3 .agents/skills/unit-economics-calc/scripts/unit_economics.py \
  --price 19 --margin 0.75 --retention 8 --cpc 2.4 --cr-landing 0.03

# скільки треба трафіку щоб результат щось означав
python3 .agents/skills/unit-economics-calc/scripts/sample_size.py size \
  --baseline 0.02 --lift 0.30

# motion-графіка з HTML у MP4
python3 .agents/skills/video-assembly/scripts/render_motion.py \
  scene.html out.mp4 --duration 5 --size 1080x1920

# повернути заархівований скіл
bash docs/restore-skill.sh --list
bash docs/restore-skill.sh <ім'я>
```

## Обмеження середовища

Мережа закрита: доступні тільки GitHub, npm/pip і MCP-сервери. Стокові фото,
CDN і зовнішні API з коду не працюють. Лендінги верстаються на inline SVG,
градієнтах і системних шрифтах. Подробиці — `docs/CAPABILITIES.md`.
