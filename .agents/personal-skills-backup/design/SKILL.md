## Brand Strategy Framework

### Brand Foundation (define before visual)
1. **Positioning**: Who is this for + what makes it different
2. **Personality**: 3 adjectives (e.g. "direct, smart, minimal")
3. **Voice**: How it speaks (formal/informal, expert/peer)
4. **Promise**: What transformation does the user get

### Visual Identity System
Always define in order:
1. Color palette (primary + secondary + neutral + semantic)
2. Typography (heading font + body font -- max 2 families)
3. Logo concept (wordmark / symbol / combination)
4. Spacing and layout principles
5. Icon style (outline / filled / duotone)
6. Photo/illustration style direction

## UI/UX Design Principles

### Information Hierarchy
1. One primary action per screen
2. Visual weight follows importance (size, contrast, space)
3. Group related items, separate unrelated ones (Gestalt)
4. White space is not empty -- it directs attention

### Landing Page Visual Checklist
- Hero section: full viewport height, single CTA above fold
- Contrast ratio: text on background min 4.5:1 (WCAG AA)
- CTA button: high contrast, large enough on mobile (44px min tap target)
- Images: consistent style and quality throughout
- Section spacing: consistent rhythm (multiples of 8px base grid)
- Mobile: check all sections collapse properly

### Component Design Patterns
```
Cards: consistent padding (16-24px), subtle shadow or border, rounded corners (8-12px)
Buttons: primary (filled), secondary (outlined), tertiary (text only)
Forms: label above field, helper text below, error state in red
Navigation: max 5-7 items, clear active state
```

## Design Review Checklist
When reviewing any design, assess:
- [ ] Is the hierarchy clear (what to look at first)?
- [ ] Is the primary CTA obvious?
- [ ] Is it consistent with brand?
- [ ] Does it work on mobile?
- [ ] Is the typography readable (size, contrast, line-height)?
- [ ] Are colors used with purpose (not decoration)?
- [ ] Is there enough white space?
